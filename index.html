Academic Project Viva Voce & Defense Guide

Q1: Why use Logistic Regression instead of Linear Regression for default prediction?

Linear regression outputs continuous values from $-\infty$ to $+\infty$, which can produce probabilities below 0 or above 1. Logistic regression applies the Sigmoid link function $\sigma(z) = \frac{1}{1+e^{-z}}$ to map all outputs cleanly into the interval $(0, 1)$.

Q2: How does Gradient Descent update the model weights?

By taking partial derivatives of the Binary Cross-Entropy loss function $J(W)$ with respect to each weight $w_j$: $\frac{\partial J}{\partial w_j} = \frac{1}{m} \sum (\hat{y}_i - y_i) x_{ij}$. The weights update iteratively: $w_j := w_j - \alpha \frac{\partial J}{\partial w_j}$.
